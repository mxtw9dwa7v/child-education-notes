# 国家区域医疗中心 上海儿童医学中心贵州医院 贵州省人民医院小儿外科综合病房开科接诊

> 更新时间：2026-09-11 (UTC+8)

**点击蓝字，关注我们**

随着综合病房的不断完善，2023年4月24日，国家区域医疗中心上海儿童医学中心贵州医院、贵州省人民医院小儿外科综合病房正式开科接诊。

据悉，林林（化名）是小儿外科综合病房开科后收治的第一个急诊患儿。4月24日，因右侧腹壁皮肤软组织感染、右臀部皮肤感染并出现皮肤破溃入科住院治疗，从入院检查到伤口痊愈，短短四天康复出院。住院期间，医生叔叔和护士姐姐们的精心诊治与护理，让这个12岁的小男孩不仅收获了健康，还收获了成长与感动。出院之际，林林亲笔手写了一封感谢信，字里行间，稚气与真情跃然纸上，并在病房的心愿树上，写下了自己的梦想：I want to be a good doctor。

 

森森（化名）是小儿外科综合病房第一个手术患儿，也是目前年龄最小的孩子，只有1岁3个月。因右侧腹股沟斜疝入院治疗，于4月27日在全麻下行腹腔镜下右侧内环口缝扎术，术后经止血补液治疗和加速康复外科护理，第二天顺利出院。

 

小儿外科主任何国庆介绍：上海儿童医学中心贵州医院小儿外科综合病房启用后，儿科诊疗服务的硬件和软件都大幅升级，就诊空间更宽敞，诊疗流程更人性化，就诊环境还充满童心童趣。我们将依托国家区域医疗中心的建设平台，借助上海儿童医学中心的专科优势，淬炼医疗技术，深耕学科建设，奋楫专业发展，打造一支有爱心、有耐心、有担当、甘于奉献、团结奋进的医护团队，为患儿提供安全、舒适、规范、周到的服务，不遗余力为儿童的生命健康保驾护航。
